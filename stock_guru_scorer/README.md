# 투자 대가 점수판 (stock_guru_scorer)

종목명·종목코드·티커를 넣으면 국내외 투자 대가 9인의 원칙으로 0~100점을 매기고,
**레이더 차트**로 "어느 대가의 철학에 맞는 종목인지"를 한눈에 보여주는 Streamlit 앱입니다.

> 과거 재무 데이터에 규칙을 적용한 참고용 점수이며 투자 권유가 아닙니다.

## 실행

```bash
cd stock_guru_scorer
pip install -r requirements.txt
streamlit run app.py
```

브라우저가 열리면 왼쪽에 종목을 입력합니다.

| 입력 예 | 의미 |
|---|---|
| `삼성전자` | 등록된 국내 종목명 (사이드바에서 목록 확인) |
| `005930` | 국내 6자리 코드 (코스피 → 코스닥 순으로 조회) |
| `AAPL`, `MSFT` | 해외 티커 |
| `AAPL, 005930, KO` | 쉼표로 최대 3개 비교 |
| `DEMO-VALUE` 등 | 인터넷 없이 체험하는 가상 기업 |

## 화면 구성

1. **종합 카드**: 종합 점수, 등급(A~E), 현재가
2. **대가별 종합 레이더**: 9명의 대가가 꼭짓점이 되는 다각형
3. **투자 성향별 적합도**: 안정·보수형 / 우량주 장기보유형 / 생활·성장 발굴형 / 데이터·원칙형 / 역발상형
4. **대가별 상세 레이더**: 각 대가가 중요하게 보는 4~6개 포인트, 실제 값, 점수, 채점 기준
5. 대가별 철학 요약과 추천 도서

## 대가별 채점 축

| 대가 | 레이더 축 |
|---|---|
| 벤저민 그레이엄 | 저평가(PER), 자산가치(PBR), 그레이엄 수(PER×PBR), 유동비율, 이익 안정성, 배당 |
| 워런 버핏 | ROE, ROE 꾸준함, 해자(영업이익률), FCF 마진, 보수적 부채, 적정 가격 |
| 피터 린치 | PEG, 이익 성장률, 재무 건전성, 재고 관리, 현금 여력 (+6유형 분류) |
| 필립 피셔 | 매출 성장, 성장 지속성, 마진 개선, R&D 투자, 수익성 |
| 앙드레 코스톨라니 | 고점 대비 낙폭, RSI 과매도, 대중 소외(거래량), 버틸 체력, 유동성 환경(직접 선택) |
| 박영옥 | 꾸준한 이익 성장, ROE, 배당, 대주주 지분, 합리적 가격 |
| 김정환 | 적정주가(EPS×ROE) 괴리, ROE, PER, 이익 모멘텀 |
| 강환국 | 밸류 종합(PER·PBR·PSR), 12개월 모멘텀, GP/A, 저변동성 |
| 이채원 | PBR, PER, 순현금/시총, 시장 소외, 배당 |

정확한 임계값은 `scoring.py`의 `GURUS` 목록에 있고, 앱의 상세 표 '기준' 열에도 표시됩니다.

## 점수 계산

- 축 점수: 지표 값을 기준선(0점)~목표선(100점) 사이에서 선형 변환
- 대가 점수: 데이터가 있는 축의 평균 (데이터 없는 축은 0점이 아니라 **제외**)
- 종합 점수: 축의 절반 이상이 채점된 대가들의 평균
- 등급: A 80↑ · B 65↑ · C 50↑ · D 35↑ · E

## 한계

- 경영진 도덕성, 현장 탐방, 사실 수집 같은 **정성 요소는 재무 지표로 근사**했습니다.
- 일부 임계값과 김정환 적정주가 공식(EPS×ROE)은 공개 자료를 바탕으로 한 **추정 해석**입니다.
- 업종 차이(금융·바이오·지주사 등)는 반영하지 않습니다.
- 데이터는 Yahoo Finance(yfinance, 비공식)이며 연간 재무가 보통 4년치입니다. 국내 종목은 일부 항목이 비어 있을 수 있습니다.

## 파일 구조

| 파일 | 역할 |
|---|---|
| `app.py` | Streamlit 화면 (레이더 차트, 표) |
| `scoring.py` | 대가 정의와 채점 규칙 |
| `data.py` | 입력 해석(종목명/코드/티커)과 yfinance 데이터 수집 |
| `samples.py` | 오프라인 체험용 가상 기업 데이터 |
| `tests/` | `pytest`로 실행 |
